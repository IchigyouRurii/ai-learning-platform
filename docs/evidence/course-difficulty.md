# 三档课程材料验证

日期：2026-11-01。

已实现：统一科目与简介输入，三次分档 AI 生成及单档补生成，三档草稿预览、编辑、详情和目录入口；旧数据阅读兼容、作者草稿三档复制、原发布快照保留；学生详情按所选难度展示进度。

验证：`pnpm lint`、`pnpm typecheck` 通过；Vitest 27 个文件共 155 项测试通过；默认 `pnpm build`（Turbopack）通过。初次构建遇本地样式编译端口权限错误，移出失败的生成缓存后以所需权限重新构建成功。未改构建配置。

新增测试覆盖旧快照不变、草稿各档独立、唯一编号与正确选项引用、科目校验、单档上限、模拟生成三档，以及嵌入式 PostgreSQL 保存/发布/公开投影。测试不访问真实 Neon，不发起真实 AI 请求。未进行浏览器验证或云端迁移。

历史发布版本没有难度标记，因此三个阅读入口展示同一份旧材料并沿用旧记录；打开编辑后复制为独立草稿，保存、发布新版本后按独立编号记录。详情见 ../engineering/course-difficulty.md。
