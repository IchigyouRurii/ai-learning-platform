# 最终交付与 presentation 工作区

指定一名统筹人，成员各自负责内容与讲述。最终提交由团队人工审核，能够解释所有内容，不直接复制未经编辑的 AI 输出。

## Presentation 故事线模板

1. 谁遇到了什么学习/教学问题，访谈带来了什么发现。
2. 一条教师到学生的完整演示流程。
3. 系统结构与关键设计选择。
4. 各成员贡献、测试和迭代证据。
5. AI 使用的有效/无效案例，AI Fluency 4D 的具体实践。
6. 挑战、解决方法与学到的内容。

原文演讲时长暂定最多 8 分钟，约 5 分钟问答；以课程方最终通知为准。

## 其他交付

- 进度讨论：1–2 页摘要，分工、设计/原型和进度。
- 公开原型链接（真实服务接入完成后）。
- 5–8 分钟系统概览视频与功能演示链接。
- 最终报告：概览、架构、功能、开发/测试/部署与协作过程。
- 使用说明：学生、教师、管理员（管理员功能需先确认）。
- 贡献表：每人的 Issue、PR、内容制作、测试与展示证据。
