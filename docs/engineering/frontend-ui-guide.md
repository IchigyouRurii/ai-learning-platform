# 前端 UI 规范 v2｜源码提取版

适用：OpenLearnING 项目全体前端开发成员。  
依据：用户提供的《教师工作台设计-原始源码.zip》中的 `src/App.tsx`、`src/index.css`、`package.json`。  
本文件替代此前基于截图推测的 v1 参数。当前集成状态和组件路径见 [公共 UI 接入](ui.md)。

## 1. 统一视觉

**保持深靛蓝、浅灰蓝背景、白色卡片、轻阴影的风格。** 新页面沿用同一外壳和基础样式，不各自设计配色、按钮或导航。

| 项目       | 源码参数／团队使用约定                                                             |
| ---------- | ---------------------------------------------------------------------------------- |
| 字体       | `Inter, "SF Pro Display", "PingFang SC", "Microsoft YaHei", system-ui, sans-serif` |
| 页面底色   | `#F5F7FB`；主内容保留原型的浅灰蓝渐变                                              |
| 默认文字   | `#17213A`                                                                          |
| 标题       | `#111C35`                                                                          |
| 正文辅助色 | `#69758A`；简介 `#738096`                                                          |
| 主按钮     | 基色 `#1C2F64`，顶部按钮 90% 不透明度；悬停 `#142653`                              |
| 难度链接   | `#244B8E`；悬停 `#0D4CB4`                                                          |
| 分类标签   | 背景 `#EDF2FB`，文字 `#315B9C`                                                     |
| 普通分隔线 | `#E9EDF4`                                                                          |

字体栈只是回退顺序，源码没有附带字体文件。字体加载由公共布局统一负责；本版不额外改成思源黑体。

## 2. 字号与布局

| 元素                   | 统一参数                                      |
| ---------------------- | --------------------------------------------- |
| 页面标题               | 30px，字重 600；字距 `-0.04em`                |
| 页面说明               | 15px，常规字重                                |
| 课程标题               | 19px，字重 600；字距 `-0.02em`                |
| 正文、导航、按钮、筛选 | 14px；课程简介行高 24px                       |
| 作者                   | 13px                                          |
| 学科标签               | 12px，字重 600                                |
| 窄侧栏                 | 64px；展开 228px；展开覆盖页面，不推挤内容    |
| 顶部栏                 | 高 60px，滚动时吸顶                           |
| 页面内容               | 最大宽 1600px，居中；左右留白 24px，宽屏 28px |
| 课程网格               | 间距 20px；原型在 ≥1280px 时三列              |
| 课程卡片               | 圆角 18px；封面高 142px，裁切填充             |
| 卡片内容               | 左右 20px，上下 16px；底部难度栏高 48px       |

**重要限制：**源码把页面最小宽度锁为 1024px，尚不能视为手机适配完成。第一版可统一验收 1280／1440px 桌面；如需手机支持，团队共同修改公共布局，不由各模块分别处理。

## 3. 共享组件：做一套，大家复用

| 组件             | 包含内容                           | 使用约定                                     |
| ---------------- | ---------------------------------- | -------------------------------------------- |
| `AppShell`       | 侧栏、顶部栏、搜索、头像、主内容区 | 业务页面只提供内容，不复制一套导航           |
| `PageHeader`     | 标题、说明、可选数量               | 页面使用相同字号和间距                       |
| `Button`         | 主按钮、次按钮、文字按钮           | 主操作实心；次操作描边或文字；支持加载和禁用 |
| `SubjectFilter`  | 学科胶囊筛选                       | 单选，当前项深蓝底白字；与搜索组合生效       |
| `CourseCard`     | 封面、学科、标题、简介、作者、难度 | 保持顺序、尺寸和阴影一致                     |
| `Dialog / Toast` | 弹窗、反馈提示                     | 全站共用，避免各页各写一种                   |

原型没有使用 shadcn/ui，而是手写组件。当前仓库已使用 shadcn/ui，统一给现有组件套用这套视觉，不再并行维护两套 Button／Dialog。

### 课程卡片与按钮细节

- 卡片：白色 90% 不透明度；默认阴影 `0 14px 38px rgba(33,49,87,.07)`。
- 悬停：上移 4px，阴影 `0 22px 50px rgba(33,49,87,.13)`，过渡 300ms；尊重减少动态效果设置。
- 封面：宽度填满，`object-fit: cover`；避免不同封面撑出不同高度。
- 简介：原型只显示一行，超出省略。课程标题正式组件统一最多两行，并预留一致高度，避免底部不齐。
- 顶部按钮和搜索框：高 36px、圆角 8px；表单主输入和提交可统一用 44px。
- 图标：常规 20px、描边约 1.8px；小箭头约 15px。沿用一套图标，不混入 emoji。

## 4. 统一交互，不照搬原型占位行为

| 位置          | 正式开发约定                                                                                   |
| ------------- | ---------------------------------------------------------------------------------------------- |
| 左侧导航      | 点击进入真实页面，保持当前项高亮；展开支持鼠标、键盘，增加明确的展开／收起入口，不能只依赖悬停 |
| 搜索          | 搜课程或发布作者；统一文案 `Search courses or authors`，因为学生也能发布                      |
| 难度入口      | `Beginner / Advanced / Expert` 点击进入对应课程详情；在详情页决定是否加入，不直接加入          |
| Create Course | 进入生成／创建流程；填写后才真正保存草稿；失败不能显示成功                                     |
| 头像          | 展开个人资料、设置、退出菜单；不能是无反馈按钮                                                 |
| 页面反馈      | 统一提供加载、空状态、错误与重试；按钮加载中不重复提交                                         |

源码的难度点击目前只弹提示，其他导航是占位页，创建草稿也只是提示，头像尚无菜单。这些是待开发功能，不属于可复用的完成实现。

交互最低要求：键盘能操作；按钮和链接有清晰焦点；弹窗支持 Escape、焦点限制和关闭后焦点恢复；学科按钮补 `aria-pressed`；普通文字对比度以 4.5:1 为验收目标。原型中的浅灰作者／提示文字仍需实测，必要时加深，不能为保持色值牺牲可读性。

## 5. 使用方法

1. 页面自动由 `src/app/layout.tsx` 引入公共主题，不要重复导入 CSS。
2. 基础组件从 `@/shared/ui/components/button` 等实际路径导入；组合组件从 `@/shared/ui/primitives` 导入。
3. 变量在 `src/shared/ui/tokens.css`；`styles.css` 映射到 shadcn/Tailwind 语义主题；`workspace.css` 统一现有业务页；`legacy.css` 仅保留旧结构兼容。
4. 新页面优先使用 `bg-background`、`text-foreground`、`text-muted-foreground`、`bg-primary` 等语义类；特殊尺寸引用 `var(--ui-...)`。不要重复写一套颜色。
5. 根布局已提供 AppShell；业务页面不再嵌套一套导航。公共样式／组件改动经 UI 负责人确认。
6. 原型 13px 作者色与说明色如不满足对比度，使用项目加深后的 `--muted-foreground`。不复制原型的 1024px 最小宽度，项目保留手机布局。

正式仓库已有 Next.js、shadcn/ui 和 Tailwind CSS 4，只迁移视觉和组件，不复制原型 Vite 配置，不覆盖 package.json。课程数据暂不支持原型全部字段；不伪造作者、公开课程、难度或跳转功能。
