# Workspace navigation performance

本地开发的首次切换包含 Next.js 页面编译，生产模式没有这部分开销；Neon/VPN 延迟仍可能影响所有需要会话和数据读取的页面。没有使用跨用户全局数据缓存或关闭身份验证。

当前优化：

- Teacher My Creation 使用 `getOwnedCourseCatalog`：从原工作台 6 组查询改为一条按作者限定的参数化元数据查询，不加载活动正文、答案、提交和反馈。
- `getWorkspace` 使用 React request cache，同一次服务端渲染的重复读取合并；不跨请求保留权限或用户数据，修改后仍重新查询。
- 学习路径已有历史时使用列表首项，省去重复读取最新路径；无历史时保留旧格式数据的兼容读取。
- 侧边栏关闭无意图的自动预加载。鼠标停留 150ms 或键盘聚焦才完整预加载，当前页不重复预加载；组件卸载时清理计时器。
- 共享工作台继续保持挂载，加载提示只覆盖内容区域。

测试覆盖作者目录隔离及不返回全文、My Creation 不再调用工作台查询、教师课程始终不显示删除，学生个人课程按所有权与依赖规则显示删除入口。未做浏览器验证或线上延迟测量，因此不承诺切换耗时或消除网络等待。
