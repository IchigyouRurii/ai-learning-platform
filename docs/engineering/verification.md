## 浏览器人工验证

使用 production build 在本机预览，实际完成：

1. 教师输入主题、目标与教学材料，生成模拟草稿。
2. 修改草稿标题，保存并重新读取预览。
3. 发布课程，在学生端看到新课程。
4. 学生加入课程，提交第一项活动并看到明确标记的模拟反馈。
5. 两项活动提交一项，进度显示 50%，切换页面后仍保留。
6. 教师查看参与进度与回答，发送反馈。
7. 学生在个人学习页看到教师反馈及已保存进度。
8. 检查默认窄屏与 1280px 桌面布局；桌面无横向溢出，浏览器无 error/warn。

人工验证创建的数据在交付前移出项目，恢复三门初始示例课程。没有连接第三方 AI 或上传学习材料到外部服务。
