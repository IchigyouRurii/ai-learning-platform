# Course deletion policy

仅学生可以删除本人创建的 personal 课程，在详情页 Edit 左侧显示 Delete；确认弹窗说明课程与自己的学习记录会永久删除，无法恢复。教师课程无论草稿、发布、是否有人加入或是否绑定班级，都不提供删除入口，也不能通过服务或 SQL 删除。管理员继续使用已有下架操作，保留课程与学习数据。

- 服务端从会话取得身份，仅允许 student；Neon 写入同时检查作者、数据库角色 student 和 visibility=personal。
- 页面 `canDeleteOwnedCourse` 使用同样角色和所有权规则。学生不能删除别人的课程、教师公开课程，管理员也不能通过此接口删除。
- 保留已有保护：如果异常历史数据让个人课程绑定了班级、分配或其他学习者，禁止删除。
- 事务中锁定课程，验证后清理作者提交、反馈和课程。版本、加入、章节完成、讨论、批注及生成历史通过已有外键级联清理；异常全部回滚。
- 删除后返回 My Learning，相关页面重新验证。已有路径中的失效引用显示 Course unavailable，可在编辑时移除。
- 无新增迁移，不批量删除现有数据；测试使用隔离数据库，不做浏览器验证。

Leave Course 继续只适用于非本人创建且不受班级管理的已加入课程，退出保留学习记录。
